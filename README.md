# 🏠 DormHub — система управління гуртожитком

**DormHub** — вебзастосунок для студентського гуртожитку коледжу, який замінює паперові журнали поселення, оплати та заявок на ремонт.

## Яку проблему вирішує
- Поселення та облік вільних місць ведуться в паперових журналах — важко швидко знайти вільне ліжко-місце.
- Студенти не знають свого боргу за проживання і стоять у черзі до коменданта.
- Заявки на ремонт («не працює кран», «перегоріла лампа») губляться.

## Основні функції
| Функція | Хто користується |
|---|---|
| Облік кімнат і вільних місць | Комендант |
| Поселення / виселення студентів | Комендант |
| Нарахування й облік оплати за проживання | Бухгалтер, студент |
| Заявки на ремонт зі статусами | Студент, черговий майстер |
| Оголошення для мешканців | Комендант |
| Реєстрація гостей | Черговий (вахтер) |

## Для кого
- **Студенти** — бачать свою кімнату, борг, подають заявки.
- **Комендант** — керує поселенням і оголошеннями.
- **Майстер / черговий** — обробляє заявки, реєструє гостей.
- **Адміністрація коледжу** — отримує звіти щодо заповненості й оплат.

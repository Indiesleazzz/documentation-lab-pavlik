# 🔌 Огляд API DormHub (демонстраційний)

Базова адреса: `https://dormhub.college.local/api/v1` · Формат: JSON · Авторизація: `Authorization: Bearer <token>`

## GET /rooms?free=true — список кімнат з вільними місцями
**Запит:**
```http
GET /api/v1/rooms?free=true
```
**Відповідь 200:**
```json
[
  { "id": 214, "floor": 2, "capacity": 3, "occupied": 2 },
  { "id": 305, "floor": 3, "capacity": 2, "occupied": 0 }
]
```

## POST /requests — створити заявку на ремонт
**Запит:**
```json
{ "roomId": 214, "category": "PLUMBING", "description": "Тече кран у ванній" }
```
**Відповідь 201:**
```json
{ "id": 1057, "status": "NEW", "createdAt": "2026-11-24T18:30:00Z" }
```

## GET /students/{id}/balance — борг студента за проживання
**Відповідь 200:**
```json
{ "studentId": 88, "debt": 1250.00, "currency": "UAH", "lastPayment": "2026-10-05" }
```

## Коди відповідей
| Код | Значення |
|---|---|
| 200 | Успішно |
| 201 | Ресурс створено |
| 400 | Некоректні дані (наприклад, порожній опис заявки) |
| 401 | Не авторизовано |
| 403 | Немає прав (студент намагається поселити іншого) |
| 404 | Не знайдено (кімната / студент) |
| 500 | Внутрішня помилка сервера |
